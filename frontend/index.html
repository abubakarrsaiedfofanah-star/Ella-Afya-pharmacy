QUICK ANSWERS

Good to know about the platform.

What the website does, how payments are recorded and how to get started.

Is this an online medicine shop?+

No. Ella Afya is a pharmacy operations system for managing stock, prescriptions, sales and business records.

Does M-Pesa payment confirmation happen automatically?+

No payment-provider API is connected. Staff check the payment in the pharmacy's M-Pesa message or statement, then record its receipt code in the system.

How can pharmacy staff get access?+

Access is managed by the pharmacy. Contact its administrator to request an account and learn about the approval process.

Can I install the website like an app?+

Yes. Use the install option when your browser offers it. Live stock, sales and payment records still need an internet connection.
